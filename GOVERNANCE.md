# Governance

Global VPC Controller is maintainer-led. The repository owner is the initial
maintainer, responsible for reviews, releases, security coordination and access.
This describes present responsibility, not an organization or a multi-maintainer
support commitment.

Propose changes through issues and pull requests. Public API, ownership,
security-boundary and destructive-lifecycle changes should include a written
design, compatibility impact and recovery approach. Consensus is preferred;
the maintainer makes the final decision when necessary.

Releases must pass documented checks and preserve maturity labels. Contributors
receive credit through Git history. Additional maintainers may be invited based
on sustained work; announce maintainership changes in the repository.

Follow the [code of conduct](CODE_OF_CONDUCT.md) and [security process](SECURITY.md).
