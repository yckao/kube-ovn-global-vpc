# Support

This project is for engineering evaluation. Maintenance is best-effort with no
paid support commitment or availability SLA.

Use [GitHub issues](https://github.com/yckao/kube-ovn-global-vpc/issues) for
reproducible defects, documentation issues and focused proposals. Include:

- the version/commit, transport and supported native adapter target;
- expected versus actual behavior and a synthetic minimal example;
- sanitized conditions, generations, error messages and checks;
- whether findings come from a unit, API or live dataplane test.

Never include kubeconfigs, tokens, private keys, real hostnames/addresses,
customer identifiers, inventories or packet payloads. Use [SECURITY.md](SECURITY.md)
for security-sensitive reports. Start with the [quick start](docs/managed-quickstart.md)
and [roadmap](ROADMAP.md).
